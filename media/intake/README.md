# Photo intake (private drop → public scatter)

Drop exports here. **Raw dumps stay out of git** (see `.gitignore`). Curated web exports are copied into `img/company/` and `img/brand/` by the agent after triage.

```
media/intake/
  raw/          ← zip / HEIC / full dump (gitignored)
  selected/
    a/          ← hero, OG, LinkedIn, press
    b/          ← company / about / shop atmosphere
    c/          ← social rotation
  REJECT.md     ← optional notes on quarantined files
```

Full plan: `docs/visual-photo-scatter.md`

**Send photos via:** Postiz upload widget in chat · chat attachments · iCloud Shared Album / Drive link · zip into `raw/`.
