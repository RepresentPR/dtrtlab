Lab Operating System

How durable companies actually run — installed here at Lab scale. Purpose → playbook → people language → scorecard → learning loop → public evidence. Full write-up: docs/lab-operating-system.md. Company study (what works / what we will not copy): docs/company-study-elon.md.

  1. Purpose — Do the right thing. Make useful stuff. Have fun doing it. Show dated evidence.
  2. Playbook — Intake → Scope → Build → Proof → Deliver → Follow-up. No owner + no dated proof = not done.
  3. Improve — Question → Delete → Simplify → Accelerate → Automate last. Never automate costume work.
  4. People language — Customer focus · Collaborates · Continuous learning · Critical thinking · Drives results · Ensures accountability.
  5. Scorecard — Ship cadence · Honesty · Kept informed · Free-plan usefulness · AFTERLIGHT progress — on /live/.
  6. Learning loop — Growing training catalog · short Required-for-You trust list · Profile → Goals → Feedback when roles exist.
  7. Quick references — Brand, legal, contact intents, partner path, shop rules in one hub — not buried in email.
