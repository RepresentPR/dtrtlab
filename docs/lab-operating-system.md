# DTRT Lab Operating System (public)

**Reviewed:** 2026-10-14  
**Status:** Operating design for how the Lab grows — not a claim of enterprise scale.

This is the structure we are installing at DTRT Lab after studying how durable multi-brand companies actually run (purpose → playbook → people language → scorecard → learning loop → evidence). Patterns only. No third-party manuals copied into this site.

**Company study (Tesla / SpaceX / X — what works vs what we will not copy):** [`docs/company-study-elon.md`](company-study-elon.md).  
**Promo videos (draft until Ian audit):** [`docs/promo-videos-post-audit.md`](promo-videos-post-audit.md).

## 1. Purpose (one sentence)

Do the right thing. Make useful stuff. Have fun doing it. Show the process with dated public evidence.

## 2. Owner’s playbook (ops journey)

Every offer follows a short numbered path with a finish line:

1. Intake (what they need)  
2. Scope (what we will / will not do)  
3. Build  
4. Proof (dated evidence on `/live/`)  
5. Deliver  
6. Follow-up (CSI-style: did we keep them informed?)

If a step has no owner and no dated proof, it is not “done.”

### 2b. Improvement algorithm (order matters)

Before adding tools or agent automation to any step:

1. Make the requirement less dumb  
2. Delete the part or process if it does not touch the outcome  
3. Simplify what remains  
4. Accelerate cycle time  
5. Automate **last**

Never automate costume work. Never delete trust surfaces (legal, security, honesty flags) without naming what they protect.

## 3. People language (competencies)

Hire, coach, and promote with the same short vocabulary:

- Customer focus  
- Collaborates  
- Continuous learning  
- Critical thinking  
- Drives results  
- Ensures accountability  

Role-specific **position commitments** live next to the free-plan / paid-work / shop paths — not in a private Slack dump.

## 4. Scorecard (what we measure in public)

| Dial | Where it shows |
| --- | --- |
| Ship / publish cadence | `/live/`, news |
| Honesty (no fake store / hiring / raise) | Company facts table |
| Kept informed (client updates) | Contact + project notes |
| Usefulness of free plans | Plan outcomes when shared |
| AFTERLIGHT progress | `/afterlight.html` |

## 5. Learning loop

- A searchable **Lab Files / training** catalog over time (Access: on-demand vs needs enrollment).  
- A short **Required for You** list for anything that protects trust (security, privacy, AI use, brand honesty).  
- Career path: Profile → Goals → Development items → Job alerts (when hiring is real) → Learning → Feedback.

## 6. Quick references (job aids)

Policies and how-tos live in one hub (not buried in email): brand kit, legal, contact intents, partner path, shop interest rules.

## 7. Brand portfolio rule

Sister offers (creator Lab, AFTERLIGHT, free plans, shop interest, future PR help) share purpose + scorecard language. Each brand still has one clear job. No fake mega-corp nav.

## 8. Out of vision

- Cloning third-party software via reverse engineering as a growth strategy  
- Fake scale, fake store, fake hiring, or fake fundraising  
- Publishing proprietary manuals from other companies  
- Shipping promo claims before an audit sign-off  
- Copying founder volatility or “intensity without structure”
