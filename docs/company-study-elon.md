## What works (steal structure)

| Pattern | How it shows up there | DTRT apply |
| --- | --- | --- |
| **First principles** | Cost/physics from materials up, not “industry always does X” | Free plan, shop, AFTERLIGHT: ask what the customer actually needs; delete costume tools |
| **The Algorithm (order matters)** | 1 Question requirements → 2 Delete → 3 Simplify → 4 Accelerate → 5 Automate last | Same order on every offer and every agent workflow. Never automate a step that should not exist |
| **Vertical integration of the critical path** | Own the hard bits (cells, engines, feed) when vendors are the bottleneck | Own proof + offer + distribution: `/live/`, company facts, free-plan path, Postiz cadence. Rent the rest |
| **Public demo over press release** | Rockets land; cars ship; founder posts the truth on X | Ian posts dated proof as himself. No Fortune tone. See founder-direct tip in daily reply pack |
| **Mission that survives a bad week** | Multi-planetary / sustainable energy is bigger than one quarter | Personal vision stays the filter: useful stuff, honesty, PR-aligned revenue snowball |
| **Tight feedback when failure is visible** | Flight tests fail in public; iterate in a wide correction window | Prefer reversible ships: drafts, interest lists, `/live/` corrections. Audit before hard claims |
| **One job per brand** | Tesla ≠ SpaceX ≠ X ≠ xAI | Lab (useful) ≠ DTRTC (entertainment) ≠ AFTERLIGHT (story world). Shared purpose language only |

## What does not work (do not copy)

| Anti-pattern | Why it fails | DTRT guardrail |
| --- | --- | --- |
| **Automate before delete** | Tesla factory lesson: robots for work that should not exist | Agent automates only after Intake→Scope proves the step is required |
| **Intensity without structure** | Same drive that works with deep ops lieutenants becomes chaos without them | Agent-first ops + Ian unlock only for credentials/direction ([`company-operating-system.md`](company-operating-system.md)) |
| **Delete fences you do not understand** | X transition: cut capacity that held trust/ads/judgment work | Before deleting a process, name what it protected. Keep honesty, legal, security contacts |
| **Narrow correction window moves** | Damage permanent before you detect it (trust, advertisers, people) | No fake store/hire/raise. Numbers re-audit before promo claims. Promo videos stay **draft** until Ian audit sign-off |
| **Press-release theater / fake scale** | Corporate posts nobody believes | Founder-direct on X; company.json stays factual |
| **Personal volatility as a management system** | Cost without breakthrough when you are not Elon with SpaceX depth | Competency language + scorecard; no demon-mode cosplay |
| **Cycle-time pressure as a substitute for capacity** | Burnout, cut corners, fraud risk | Scorecard includes honesty + kept-informed, not vanity velocity alone |

## Operating algorithm (DTRT wording)

Install on every offer and every agent task:

1. **Make the requirement less dumb** — What outcome does the visitor/client actually need?  
2. **Delete** — Cut pages, tools, posts, and steps that do not touch that outcome.  
3. **Simplify** — One CTA. One job per section. One truth in company facts.  
4. **Accelerate** — Ship the thin honest version this week.  
5. **Automate last** — Postiz, agents, email routing — only after 1–4.

If you are not occasionally putting a deleted thing back (~10% of the time), you are not deleting enough — but never delete trust surfaces (legal, security, honesty flags).

## Distribution algorithm (X + short video)

Stolen from observed founder behavior + small-account practice — not from scraping private data:

1. **Founder-direct** beats press release.  
2. **Reply-to-10** real observations daily beats lonely broadcasting.  
3. **Product/demo** in the first seconds; spell domains; no link spam in replies.  
4. **Dual brand** stay separate: Lab usefulness vs DTRTC entertainment.  
5. **Audit before promo** — drafts ready; publish after Ian signs the numbers/claims.

Unlock: agent browser is not logged into X — Ian pastes replies or logs the agent in.
