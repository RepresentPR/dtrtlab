## Apply (DTRT-safe)

### 1. Founder-direct > press release

- Post from the founder voice (Ian / Lab account), first person, dated facts.
- Prefer: “what shipped / what’s not live / where to look.”
- Avoid: third-person company announcements, “we’re excited to announce,” fake Fortune tone.
- Press pages stay for journalists; the timeline is for operators and curious humans.

### 2. Reply-to-10 (every day)

- Morning 5 + afternoon 5 — see paste pack in `docs/social-reply-daily.md`.
- One real observation per reply. No “great post!!”, no link spam, no pitch unless asked.
- Prefer 10k–1M accounts with live threads over mega-celeb voids.
- Log traction in `content/growth-ledger.json`.

### 3. High-signal short posts

- Default: 1–3 short lines. One idea. Cut adjectives that don’t add proof.
- Spell domains as `dtrtlab dot com` on X when Postiz/X strips bare URLs.
- Threads only when a checklist or scorecard needs structure (e.g. Lab OS).

### 4. Product demo over corporate speak

| Prefer | Avoid |
| --- | --- |
| Screenshot / page / clip of the real thing | “Synergy”, “platform”, “revolutionizing” |
| “Checkout is not live” | Fake buy-button energy |
| Free plan → what they get | Vague “reach out to learn more” |
| AFTERLIGHT “in development” | Console-deal theater |

Demo order for Lab: **live page or clip → one sentence of truth → one CTA** (free plan or `/live/`).

### 5. Cadence (default week)

| Slot (UTC-ish) | What |
| --- | --- |
| Daily | Reply-to-10 (paste pack or agent session after Ian unlocks X login) |
| 3× / week | Founder-direct short post (truth + proof) |
| Wave queue | Postiz QUEUE for Lab face (IG/TT/YT) — keep DTRTC stream separate |
| After ship | One demo post the same day something becomes publicly true |

Do not flood. One honest post beats five costume posts.
