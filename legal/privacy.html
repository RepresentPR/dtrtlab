Privacy

The game is offline. Training saves, settings, and scores stay on the player’s PC. The game does not create an account or upload results. If you only play the Windows RC, nothing is stored in the cloud.

This website: if you submit a contact or bug form, the site server stores the fields you typed (name, email, message, hardware notes) in a local inbox file on the host machine. No third-party analytics ship in these pages. Payments, when enabled, are handled by PayPal — we do not collect card numbers or PayPal passwords.

Cookies: none required for reading the site.
